# 动画课与语音（2026-11-18）

进入课本辅导，选择第一单元，再选“单词情境动画”“句型动画讲解”或“阅读故事讲解”。四、五年级各有三节配套原创课。DeepSeek 根据已有原创教案生成旁白，网页用动作插画、词句卡片、语音与分句字幕讲解；可以暂停、切幕、重播、调语速和继续向小芽提问。没有配置模型时明确标记为离线原创教案。这些内容不是教材原文，不声称覆盖完整单元。

拍题识别后点击“确认并生成讲解视频”，会保存题目、退出识别草稿并立即提交板书视频任务。进度和完成后的 MP4 在页面显示，任务记录可重新打开。若提交任务失败，已确认题目仍保留，可以重试生成。

语音在本机通过 Kokoro 合成，不产生云端语音调用费。首次生成需要时间，较长讲稿需要更久；当前正在执行的视频任务也可能造成等待。缓存音频通过 API 直接返回，不再进入媒体队列；重复的待生成朗读复用同一任务，待处理朗读优先于尚未开始的视频任务。正在制作中的视频不会被中断。

固定动画课在发布前预生成全部讲稿及语音，保存在 `content/prepared-lessons`，随免安装包一起分发。当前四、五年级第一单元共六课、二十幕。打开已准备课程无需再次调用 DeepSeek 或启动语音合成；同年级学生共享这些不含个人信息的原创课程素材。音频接口仍检查年级和测评锁。课程未预生成时明确走现场准备流程，不伪装成已准备。

新增课件后可在已配置好模型的项目环境运行 `npx tsx scripts/prepare-lessons.ts`；只有整课音频全部完成，才会发布这课的资源清单。脚本会复用已经完成的课程，校验英文发音词表，阻止遗漏词语的课件发布。修改原始教案后，课程内容指纹会自动变化，须重新准备。

拍题和辅导的新文字出现后，会立即准备最新回答的语音；不会一次性为整个聊天历史排队。用户临时提问不能预知，立即点击仍可能等待尚未完成的合成。私人回答音频继续按学生隔离。朗读按钮显示准备/停止状态，取消后不会在稍后突然出声。字幕按音频进度分段呈现，并非逐词强制对齐。

动画课是网页动态课件；拍题板书讲解才是可下载 MP4。看动画或进行辅导不直接计为掌握，也不改动独立测评成绩。
