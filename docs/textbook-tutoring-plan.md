更新日期：2026-11-18。产品面向新版人教 PEP 四、五年级上册，以改善独立作答与实际考试表现为目标，以理解课文、解释词句、学生表达和错因修复为路径。练习只用于诊断与确认，首页围绕“今天哪一课、哪里不懂、怎样学会”组织，不以累计刷题量作为主要目标。

**现存 80 道题是此前的通用演示样题，不是新版同步正式题库。** 其旧有知识点、前后测与延迟测结构不能因为界面切换到新版，就被自动声明为新版教材对齐。下一阶段应按新版已审核教学目标逐步替换题目与测评卷，保留旧记录及其来源标签；旧题确有适用价值时也须逐题审核映射，不批量改标签。现有分数可验证程序流程，不能直接作为新版课程效果证据。

当前所有辅导正文、短文和迁移题均为“教材主题配套原创辅导”，不是课本原文；尚未取得完整教材正文或学生实际试卷。

五年级的性格行为分析与人物证据阅读可复用原有“性格特点”“人物阅读”分类，不重复建立相同知识点。原有 8 个知识点及其关联题目保持不变；新增分类仅提供准确归类的入口，不自动改变旧样题的教材对应关系。

## 3. 四条学习流程

| 场景 | 学生与助教如何配合 | 留下什么证据 |
| --- | --- | --- |
| 课前预习 | 选择当周单元与材料；看情境、说已有认识；听读少量关键词句；提出一个想弄懂的问题 | 预习问题、初次表达及需要教师解释的地方 |
| 课中难点 | 学生指出具体词、句或段落；先判断卡在词义、句意还是信息关系；用一个例子解释；让学生换自己的话说明；不懂则停在本步继续讲 | 困惑原话、引用材料、讲解步骤、学生修正前后的表达 |
| 试卷失分回归知识 | 先核对原题、选项、学生答案和教师答案；区分知识缺口、读题偏差与证据定位问题；定位相应教材目标；补讲后用不同情境做一次迁移 | 原题来源、教师核对、错因依据、回到哪个知识点、迁移结果 |
| 课后复述与少量确认 | 脱离示范复述关键意思或完成小表达；用一题确认是否能迁移；仍不理解则回讲；隔天再做少量独立回忆或应用 | 学生复述原文、一题确认、自评、后续独立表现 |

四上首单元先从家庭成员的活动与分工理解词句，再让学生表达自己能怎样帮忙；后续与实际教材页核对职业、家务和相关问句的范围。五上首单元从人物信息理解外貌、特点与能力，要求以行为支持判断，再完成朋友介绍。两者都应先理解内容和表达意图，再关注句式是否正确。

## 4. 家长能看到的学习证据

家长摘要应回答四件事：孩子今天哪里不懂、经过怎样的解释、现在能否自己说明、下一次需要关注什么。以学生真实表达和作答记录为依据，分别展示：

- **辅导过程**：主题、材料来源、学生提问、关键复述、获得的提示与仍未解决的问题。
- **辅导后表现**：一题迁移结果和学生自评，明确是接受帮助之后的表现。
- **独立表现**：无提示的新题首答、教师核对后的单元测评、具有真实间隔的后续检验。
- **实际成绩**：由家长或教师提供的学校试卷、日期、满分和评分依据；尚未接入时不编造数值。

“看过视频”“完成对话”“学生自称听懂”不等于掌握；辅导后答对不能混入独立首答正确率。成绩比较需标明覆盖知识点、题量、难度与间隔，样本不足时只报告事实。产品不承诺提分，也不把一次成绩变化归因于 AI。

## 5. 教师审核与原文对齐

新增单元或试卷题，按以下顺序审核后发布：

1. **确认来源**：记录出版社、教材系列、册别、版权页版次、单元和页码；试卷另记出处、卷类型、日期、题号与获取方式。
2. **核对材料**：检查照片或合法获得的原文与识别文本是否一致，尤其是选项、否定词、图示、空格和听力条件；材料不全时不猜答案。
3. **建立对应**：指出原文句段、教学目标与题目要求之间的实际联系，区分“单元名匹配”“主题相近”“原文与目标已核验”。
4. **审查讲解**：判断答案、例子、难度与表达是否适龄；原创延伸不得伪装为教材内容或原卷解析。只有目录时，助教必须说明依据有限。
5. **保留版本**：保存审核人、时间、修改理由和题目版本；答案修订后检查受影响记录。未审核内容继续作为草稿，不进入新版正式成绩口径。

上述完整来源台账和教材页级对齐属于下一阶段建设项；当前已有题目审核机制，尚不等于已经完成整册教材对齐。

## 6. 模型分工与成本策略

| 能力 | 使用原则 | 复用方式 |
| --- | --- | --- |
| DeepSeek | 围绕已确认材料进行问诊、释义、分步解释和个别反馈；拍题和语音转写按需调用 | 限制上下文与输出长度；复用已完成请求；同一疑问优先调用已审核讲解 |
| Qwen | 只在情境图确实有助理解时生成插图；图中文字、人物和情节需检查 | 优先复用内置原创插图与审核后的角色、场景，不为每轮对话重新出图 |
| 本地 Kokoro | 承担双语朗读与旁白，按句段处理语言 | 缓存相同文本、声音与语速的音频，本地重复播放无需云端推理 |
| 模板视频 | 用已审核讲解、重点高亮、插图和本地旁白合成短视频 | 优先生成单元共用片段；更改个别步骤时复用已完成素材，避免逐次生成完整视频 |

当前已有请求缓存、音频缓存、任务阶段复用和调用前预算预留；缓存主要按学生与内容隔离。下一阶段把**审核通过的公共教学素材**单独纳入共享库，个人对话与作答仍保持隔离。视频用于回看难点，不能取代学生表达与教师判断。

沿用项目 90 元可调用额度、10 元计费差额预留；达到上限停止新增付费任务。实际费用以服务商账单为准。密钥缺失时明确使用本地原创引导，不宣称已完成真实云模型分析；云接口配置状态也不等同于已完成真实账户验收。

## 7. 下一阶段交付与验收

先做两册首单元的可审查闭环，再按学校进度扩大范围：

1. **首单元对齐**：取得实际教材页或授权材料，教师逐项审核 6 张辅导卡和对应样卷能力要求；补齐缺漏，记录版本与来源。
2. **替换演示题**：为已审核目标建立原创、适龄的独立诊断与平行确认题，分离旧通用样题；测评题之间控制知识点与难度可比，不复用刚讲过的答案作为效果证据。
3. **完善证据页面**：展示学生表达、帮助程度、单次确认与后续独立成绩，支持教师纠正和家长回看；不合成为来源不明的“掌握分”。
4. **扩展其余十个单元**：逐单元完成来源核验、词句与阅读辅导、学生表达任务、少量确认和教师审核后再开放。

验收重点是学生能否解释、表达并在新情境中独立应用，以及错误能否被有依据地修复；不能用题量、对话轮数或视频数量代替学习结果。
